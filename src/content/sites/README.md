# src/content/sites/

유적별 콘텐츠 데이터입니다. **여기는 코드가 아니라 데이터입니다.**

```
sites/
├── bokamri.quests.json     복암리 고분군 퀘스트 체인
├── bokamri.npcs.json       (예정) NPC 배치·대화
├── bokamri.puzzles.json    (예정) 퍼즐 정의
└── ...
```

## 규칙

1. 모든 파일은 `../schema.ts` 의 타입을 따릅니다.
2. 퀘스트에는 **`learning` 필드가 필수**입니다. 무엇을 가르치는지 못 적으면
   그 퀘스트는 만들 이유가 없습니다.
3. 도감 항목에는 **`source` 필드가 필수**입니다. 출처 없는 문화재 정보는
   커밋하지 않습니다.
4. 새 유적을 추가할 때 `src/game/` 을 수정해야 한다면, 그건 엔진에 하드코딩된
   부분이 있다는 뜻입니다. 데이터로 뺄 수 있는지 먼저 검토하세요.

## 현재 상태

`bokamri.quests.json` 은 **기획 초안**입니다. 실제 구현 전
국립나주박물관 · 국가유산 지식이음의 발굴조사 보고서로 전수 검증이 필요합니다.
→ `docs/04-CONTENT-bokamri.md`
