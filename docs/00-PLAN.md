# Quest on Naju — 전체 기획 (발표용 요약)

> 코드네임: **나주 해설사 로드** (Quest on Naju)
> 한 줄 소개: **나주를 3D로 걸어 다니며, 퀘스트를 깨면서 문화재를 배우고, 「나주 최고 해설사」가 되는 웹 게임.**

---

## 1. 무엇을 만드는가

브라우저에서 바로 열리는 3D 나주. 플레이어는 누더기 옷을 입은 견습 해설사로
시작해서, 나주 곳곳의 문화유산 현장을 찾아다니며 퀘스트를 해결합니다.
퀘스트를 깨면 경험치와 장비를 얻고, 레벨이 오르면 복장이 바뀌고,
최종적으로 **「나주 최고 해설사」** 칭호를 얻습니다.

핵심은 **"공부시키지 않고 배우게 하는 것"** 입니다. 문화재 설명을 읽히는 게
아니라, 그 설명을 알아야만 풀리는 퍼즐을 줍니다.

### 세 겹의 구조

| 층 | 무엇 | 레퍼런스 |
| --- | --- | --- |
| **바깥 – 월드** | 나주 전역 맵. 유적지 사이를 걸어서 이동, 지도에 `!` 아이콘 | WoW 오픈월드 / 이미지 1의 나주 메타버스 |
| **중간 – 유적지** | 복암리 고분군 등 개별 유적. 자유 탐험 + NPC 해설 | 어쌔신 크리드 *Discovery Tour* |
| **안쪽 – 퍼즐** | 고분 내부 발굴·복원 방탈출 챔버 | 인디아나 존스 / 방탈출 게임 |

---

## 2. 핵심 게임 루프

```
   나주 월드맵 이동
        │
        ▼
   ! 느낌표 NPC 발견  ──►  퀘스트 수락 (퀘스트 로그에 등록)
        │
        ▼
   유적지 진입 (씬 전환)
        │
        ├─► 탐험: 유물·구조물에 다가가면 해설 카드 팝업 (= 지식 습득)
        │
        └─► 퍼즐 챔버: 방탈출식 문제
              「방금 본 옹관의 매장 방식은?」
              「이 토기 조각들을 원래 형태로 맞춰라」
              └─► 정답의 근거가 반드시 씬 안에 존재해야 함
        │
        ▼
   퀘스트 완료 → 경험치 + 장비 + 도감 항목 해금
        │
        ▼
   레벨업 → 복장 변화 · 새 지역 해금 · 새 퀘스트 개방
        │
        └───────────► (반복)
```

**설계 원칙:** 정답은 절대 밖에서 검색해 오는 것이 아니라, **그 씬 안을 잘 본
사람만** 알 수 있어야 합니다. 그래야 "게임을 하니 저절로 외워졌다"가 됩니다.

---

## 3. 성장 시스템 — 누더기에서 해설사까지

| 레벨 | 칭호 | 복장 | 해금 |
| --- | --- | --- | --- |
| 1–4 | 길 잃은 나그네 | 누더기 삼베옷, 맨발 | 시작 마을, 튜토리얼 유적 |
| 5–9 | 견습 답사꾼 | 무명 저고리, 짚신, 봇짐 | 복암리 고분군 |
| 10–14 | 기록하는 자 | 중치막, 붓과 서책 | 나주향교, 금성관 |
| 15–19 | 나주 통(通) | 도포, 갓, 등불 | 나주읍성 4대문, 영산강 권역 |
| 20 | **나주 최고 해설사** | 관복 + 해설사 인장, 이펙트 | 명예의 전당, 자유 해설 모드 |

장비는 **성능이 아니라 표현**입니다. (전투 스탯이 없으므로 밸런싱 부담 없음)
다만 일부 장비는 기능을 줍니다 — 예: `붓과 서책`을 얻어야 탁본 퍼즐 가능,
`등불`이 있어야 고분 내부 어두운 구역 진입 가능. **장비 = 열쇠**로 쓰면
"레벨을 올릴 이유"가 자연스럽게 생깁니다.

---

## 4. 콘텐츠 범위 (1차 목표)

나주 전체를 한 번에 만들지 않습니다. **복암리 고분군 하나를 끝까지** 만들어
재미가 검증되면, 같은 틀에 다른 유적을 부어 넣습니다.

| 순서 | 유적 | 배우는 것 |
| --- | --- | --- |
| 0 | 나주 월드맵 (허브) | 나주의 지리, 영산강 |
| **1** | **복암리 고분군** ★1차 | 옹관묘, 마한·백제 전환기, 발굴 방법론 |
| 2 | 국립나주박물관 | 유물 보존·전시, 도감 완성 |
| 3 | 나주향교 · 대성전 | 조선 교육제도, 건축 배치 |
| 4 | 금성관 | 객사, 관아 건축 |
| 5 | 나주읍성 (남고문 등) | 읍성 구조, 방어 체계 |

## 5. 기술 스택 결론

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 렌더링 | **Three.js** + React Three Fiber | 요청 사항. R3F로 씬을 컴포넌트로 관리 |
| 프레임워크 | React 19 + TypeScript + Vite | 빠른 HMR, 정적 배포 가능 |
| 상태 | Zustand | 퀘스트·인벤토리·진행도. R3F와 궁합 좋음 |
| 물리 | Rapier (`@react-three/rapier`) | 캐릭터 이동/충돌. WASM이라 가볍고 빠름 |
| 에셋 | glTF + Draco/Meshopt 압축 | 모바일 로딩 시간 |
| 저장 | 1차 localStorage → 2차 Supabase | 로그인 없이 시작, 나중에 계정 붙이기 |
| 멀티플레이 | **1차에서는 안 함** | 아래 6번 참조 |

자세한 근거는 [`03-TECH-ARCHITECTURE.md`](03-TECH-ARCHITECTURE.md).

## 6. 의도적으로 **빼는** 것 (1차)

만들고 싶은 걸 다 넣으면 아무것도 완성되지 않습니다. 1차에서 뺍니다:

- ❌ **멀티플레이 / 실시간 동접** — 레퍼런스(이미지 1, 2)는 게더타운형이지만,
  서버·동기화·모더레이션 비용이 게임 자체보다 큽니다. 콘텐츠가 재미있는지
  먼저 검증하고, 그 다음에 붙입니다. (구조는 열어둠 → `03-TECH` 참조)
- ❌ **음성/화상 채팅** — 학교 배포 시 관리 부담이 큽니다.
- ❌ 전투 시스템 — 이미지 3의 액션 RPG 스타일은 **연출로만** 차용하고,
  "몬스터를 때린다"가 아니라 "퍼즐을 푼다"가 핵심 동사입니다.
- ❌ 나주 전 지역 — 복암리 하나부터.

## 7. 지금 가장 큰 리스크 3가지

1. **3D 에셋 제작량.** 고분군 하나를 제대로 만들려면 모델링이 상당합니다.
   → **완화책:** 국가유산청이 2026년 6월 3D 에셋 545건을 무료 개방했습니다
   ([리서치 문서](01-RESEARCH.md) 참조). 여기서 받아 쓰고, 없는 것만 제작.
   미술 방향은 이미지 3처럼 **로우폴리 스타일라이즈드**로 잡아 제작량과
   모바일 성능을 동시에 잡습니다.
2. **고증.** 문화재를 다루므로 틀린 정보를 가르치면 안 됩니다.
   → **완화책:** 모든 학습 콘텐츠를 `src/content/` 아래 JSON으로 분리하고
   각 항목에 **출처(source)를 필수 필드**로 둡니다. 전문가 검수 가능한 형태.
3. **"교육"과 "게임"의 균형.** 재미없으면 안 하고, 안 하면 안 배웁니다.
   → **완화책:** 복암리 한 곳을 만들어 실제 학생에게 붙여보고 판단.
