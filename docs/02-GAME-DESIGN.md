# 게임 디자인 상세

---

## 1. 플레이어 판타지

> "나는 나주에 대해 아무것도 모르는 나그네였는데,
> 발로 뛰고 직접 파보면서, 결국 나주를 가장 잘 아는 사람이 되었다."

**동사(verb)는 '외운다'가 아니라 '알아낸다'입니다.** 이 구분이 프로젝트 전체를
결정합니다. 설명문을 읽히면 교육 자료가 되고, 알아내게 만들면 게임이 됩니다.

## 2. 퀘스트 시스템 (WoW 구조 차용)

### 2.1 느낌표 · 물음표

WoW의 검증된 시각 문법을 그대로 씁니다. 별도 설명 없이 누구나 이해합니다.

| 표시 | 의미 |
| --- | --- |
| **금색 `!`** | 수락 가능한 새 퀘스트 |
| **회색 `!`** | 레벨이 부족해 아직 못 받는 퀘스트 |
| **금색 `?`** | 완료 조건을 채워서 보상을 받을 수 있음 |
| **회색 `?`** | 진행 중이지만 조건 미달 |
| **파란 `!`** | 선택 퀘스트 (심화 학습 · 고득점용) |

구현: NPC 머리 위 빌보드 스프라이트 + 부드러운 상하 bobbing.
화면 밖 NPC는 화면 가장자리 **방향 인디케이터**로 표시 (이미지 2의 화살표 포탈과 유사).

### 2.2 퀘스트 타입

| 타입 | 플레이어가 하는 일 | 배우는 것 |
| --- | --- | --- |
| `OBSERVE` **관찰** | 지정된 지점에 가서 대상을 살펴본다 | 형태·규모의 체감 |
| `COLLECT` **수집** | 흩어진 유물 조각·기록을 모은다 | 유물의 종류 구분 |
| `EXCAVATE` **발굴** | 층위를 따라 조심스럽게 파낸다 | 발굴 방법론, 층위학 |
| `RESTORE` **복원** | 파편을 맞춰 원형을 되살린다 | 기물의 구조와 용도 |
| `INTERPRET` **해설** | 관람객 NPC의 질문에 답한다 | **최종 확인 — 남에게 설명하기** |
| `ESCAPE` **방탈출** | 잠긴 챔버의 연쇄 퍼즐을 푼다 | 종합 |

`INTERPRET`이 이 게임의 정체성입니다. 최종 목표가 "해설사"이므로,
**배운 것을 남에게 설명할 수 있는지**로 숙련도를 측정합니다.
관람객 NPC가 "이 항아리는 왜 두 개를 맞붙여 놨나요?"라고 물으면
플레이어가 답을 고릅니다. 이건 퀴즈가 아니라 **역할극**입니다.

### 2.3 퀘스트 데이터 스키마

퀘스트는 코드가 아니라 **데이터**입니다. 기획자가 JSON만 추가하면
새 퀘스트가 생겨야 합니다.

  "site": "bokamri",

  "prerequisites": ["bokamri-00-arrival"],
  "giver": { "npc": "npc-excavation-lead", "marker": "!" },
  "turnIn": { "npc": "npc-excavation-lead", "marker": "?" },

  "dialogue": {

    "progress": "아직 흙을 덜 걷어냈군.",
    "complete": "제법인데? 자네 손끝에 눈이 달렸군."
  },

  "objectives": [
    { "id": "o1", "kind": "reach",    "target": "trench-3",       "label": "3호 트렌치로 가기" },
    { "id": "o2", "kind": "interact", "target": "layer-marker-a", "label": "층위 표지 확인", "count": 3 },

명시하지 못하면 그 퀘스트는 만들 이유가 없습니다.

## 3. 퍼즐 설계 — 방탈출 + 인디아나 존스

### 3.1 절대 규칙

> **정답의 근거는 반드시 그 씬 안에 있어야 한다.**

밖에서 검색해야 풀리는 문제는 만들지 않습니다. 학생이 벽에 붙은 안내판을
읽고, 유물의 형태를 관찰하고, NPC의 말을 기억해서 푸는 것 — 이것만이
"게임하면서 배웠다"를 만듭니다.

### 3.2 퍼즐 아키타입 6종

| # | 이름 | 메커닉 | 배우는 것 | 난이도 |
| --- | --- | --- | --- | --- |
| 1 | **층위 읽기** | 뒤섞인 지층 단면을 오래된 순서로 정렬 | 층위학의 기본 원리 | ★☆☆ |
| 2 | **토기 복원** | 3D 파편을 회전·스냅해서 원형 조립 | 기물의 형태와 용도 | ★★☆ |
| 3 | **탁본** | 비문·문양 위를 문질러 글자를 드러냄 | 명문, 기록의 가치 | ★☆☆ |
| 4 | **부장품 배치** | 유물을 원래 놓였던 위치에 배치 | 매장 의례, 위계 | ★★★ |
| 5 | **연대 사슬** | 유물·사건을 시대순으로 연결 | 시대 감각 | ★★☆ |
| 6 | **해설 문답** | 관람객 질문에 정확히 답하기 | 종합·표현 | ★★★ |

### 3.3 발굴 미니게임 (인디아나 존스 파트)

오너 요구사항 "뭔가 발굴하고 제작하는" 의 핵심 구현입니다.

```
  [ 트렌치 격자 위에서 도구를 골라 파낸다 ]

  도구:  🔨 곡괭이  →  빠름 · 유물 손상 위험 높음
         🥄 흙손    →  보통 · 안전
         🖌 솔      →  느림 · 손상 0 · 미세 노출 전용

  손상 게이지가 100%가 되면 유물이 깨집니다.
  → "빨리 파고 싶은 욕구" vs "조심해야 한다는 규칙"의 긴장이 곧 학습입니다.
     실제 발굴이 왜 그렇게 느린지를 몸으로 알게 됩니다.

  파낸 조각 → 인벤토리 → [복원 작업대] → 완성품 → 도감 등록
```

이 루프가 **"발굴 → 제작"** 요구를 그대로 충족합니다.
그리고 여기서 나온 복원품이 곧 **장비**가 되어 성장으로 이어집니다.

## 4. 성장 시스템

### 4.1 경험치와 레벨

| 행동 | XP |
| --- | --- |
| 주요 퀘스트 완료 | 200–400 |
| 선택 퀘스트 완료 | 100–200 |
| 도감 항목 최초 해금 | 50 |
| 퍼즐 무실수 클리어 | +50 보너스 |
| 유물 손상 없이 발굴 | +30 보너스 |
| 관람객 해설 정답 | 80 |

최대 레벨 20. 곡선은 완만하게 — 좌절보다 진도감이 중요합니다.

### 4.2 장비 = 열쇠

복장은 성능이 아니라 **표현 + 접근 권한**입니다.

| 아이템 | 획득 | 기능 |
| --- | --- | --- |
| 짚신 | Lv.5 | (외형) 맨발 탈출 |
| **흙손** | 복암리 첫 퀘스트 | 발굴 미니게임 해금 |
| **솔** | 발굴 3회 무손상 | 미세 유물 발굴 가능 |
| **붓과 서책** | Lv.10 | **탁본 퍼즐 해금** |
| **등불** | Lv.15 | **고분 내부 암부 진입 가능** |
| 갓 · 도포 | Lv.15 | (외형) |
| **해설사 인장** | Lv.20 | 자유 해설 모드 · 명예의 전당 |

이렇게 하면 "레벨을 올려야 갈 수 있는 곳이 생긴다" → **되돌아올 이유**가
만들어집니다. WoW가 하는 일이 정확히 이겁니다.

### 4.3 복장 변화 구현

캐릭터 모델 하나에 **교체 가능한 메시 슬롯**을 둡니다.
(몸통 / 하의 / 신발 / 머리 / 등짐 / 손)
전신 모델을 레벨마다 새로 만들지 않습니다 — 조합으로 5단계를 표현합니다.
스켈레톤을 공유하므로 애니메이션은 한 벌만 만들면 됩니다.

## 5. 도감 (Codex)

플레이하며 해금한 문화재·용어가 쌓이는 개인 도서관.
**게임을 끄고 나서도 남는 학습 결과물**이며, 학교에서 쓸 때는 이게 곧
평가 자료가 됩니다.

```jsonc
{
  "id": "bokamri-ongan-burial",
  "name": "옹관묘(甕棺墓)",
  "category": "매장시설",
  "site": "bokamri",
  "summary": "큰 항아리를 관으로 사용한 무덤. 영산강 유역에서 특히 발달했다.",
  "unlockedBy": "bokamri-01-first-dig",
  "model": "/models/heritage/ongan.glb",
  "source": {
    "name": "국가유산포털",
    "url": "https://www.heritage.go.kr/",
    "license": "공공누리 제1유형",
    "verifiedAt": "2026-08-07"
  }
}
```

> `source`는 **필수 필드**입니다. 출처 없는 학습 콘텐츠는 커밋하지 않습니다.
> 문화재를 다루는 이상 이건 타협 대상이 아닙니다.

## 6. 온보딩 (첫 5분)

첫 5분에 재미를 못 느끼면 나머지는 없습니다.

1. **0:00** — 누더기 차림으로 나주역 앞에 떨어짐. 조작은 이동뿐.
2. **0:30** — 금색 `!` 를 단 노인이 눈앞에. 다가가면 자동 말 걸기.
   → "자네, 복암리라고 아는가?" (모른다고 답할 수밖에 없음)
3. **1:00** — 첫 퀘스트: *"저 언덕까지 가보게."* 이동만으로 클리어.
   → **첫 XP 획득.** 레벨 2. 짚신 지급. (즉시 보상)
4. **2:00** — 언덕 위에서 복암리 고분군 전경이 열림 (카메라 연출).
   → 지형이 곧 정보라는 걸 체감.
5. **3:00** — 발굴단장 NPC가 **흙손**을 줌. 첫 발굴 미니게임.
6. **5:00** — 첫 토기 조각 획득 → 도감 첫 항목 해금.
   → "모으고 싶다"는 감각이 켜짐.

**5분 안에: 이동 · 대화 · 퀘스트 · 보상 · 레벨업 · 발굴 · 도감을 전부 경험합니다.**

## 7. 대상 사용자와 톤

- **주 대상:** 초등 고학년 ~ 중학생 (사회/역사 교과 연계)
- **부 대상:** 나주 방문객, 지역 학습 프로그램
- **톤:** 진지하되 무겁지 않게. 문화재를 다루므로 **가벼운 농담은 NPC의 성격**으로
  풀고, **문화재 정보 자체는 정확하게** 씁니다. 이 둘을 섞지 않습니다.
- **접근성:** 자막 필수, 색맹 대응, 조이스틱/키보드 양쪽 지원,
  저사양 모드(이미지 1의 "저전력 모드 실행"이 좋은 선례)
