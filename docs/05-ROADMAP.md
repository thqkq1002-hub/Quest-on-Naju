# 로드맵

기간은 **작업량 기준의 목표치**입니다. 인력 규모에 따라 조정합니다.

---

## P0 · 기술 검증 (1–2주)

> **질문:** "이미지 3 같은 게 진짜 웹에서 돌아가는가?"
> 이 답이 안 나오면 나머지 계획은 의미가 없습니다.

- [ ] Vite + React + R3F + Rapier 프로젝트 셋업
- [ ] 로우폴리 테스트 지형 위를 걸어 다니는 캐릭터
- [ ] 3인칭 카메라 추적
- [ ] **모바일 가상 조이스틱** + 데스크톱 WASD
- [ ] NPC 하나에 `!` 마커 → 다가가면 대화창
- [ ] **실기기 측정** — 중급 안드로이드 태블릿에서 fps / 로딩 시간
- [ ] 국가유산청 3D 에셋 545건에서 **나주 관련 항목 실제 조사**
- [ ] glTF Draco 압축 파이프라인 확인

**완료 기준:** 폰 브라우저에서 열어 30fps 이상으로 걸어 다니고 NPC와 대화된다.

**여기서 실패하면:** 스코프를 줄입니다 (3D 유지 + 유적지 규모 축소,
또는 월드맵만 2D 지도로).

---

## P1 · 수직 슬라이스 — 복암리 (4–6주)

> **질문:** "이게 재미있는가? 진짜 배워지는가?"

- [ ] 퀘스트 엔진 (JSON 데이터 → 상태 → UI 전체 경로)
- [ ] 대화 시스템 + 자막
- [ ] 복암리 고분군 야외 씬
- [ ] **발굴 미니게임** (도구 3종, 손상 게이지)
- [ ] **토기 복원 퍼즐**
- [ ] 3호분 챔버 방탈출 (`bokamri-05-layers`)
- [ ] XP · 레벨 · 장비 슬롯 교체 (누더기 → 무명옷)
- [ ] 도감 UI + 복암리 항목
- [ ] 퀘스트 체인 `00` ~ `06` 전부
- [ ] localStorage 저장/불러오기
- [ ] **학생 대상 플레이테스트 (최소 5명)**

**완료 기준:** 처음 열어서 복암리를 완주하고 Lv.10에 도달할 수 있다.
플레이테스트에서 "옹관묘가 뭐야?"에 학생이 답할 수 있다.

**이 단계가 프로젝트의 진짜 결정 지점입니다.** 여기서 재미없으면
유적을 더 늘려도 재미없습니다.

---

## P2 · 월드 확장 (6–8주)

- [ ] 나주 월드맵 (허브) + 유적 간 포탈
- [ ] 국립나주박물관 씬
- [ ] 나주향교 · 대성전 씬
- [ ] 금성관 씬
- [ ] 퍼즐 아키타입 나머지 (탁본, 부장품 배치, 연대 사슬)
- [ ] `INTERPRET` 해설 퀘스트 확장
- [ ] Lv.20 · **「나주 최고 해설사」** 칭호 + 최종 복장
- [ ] 도감 완성 + 수집률 표시
- [ ] 사운드 · BGM

**완료 기준:** 유적 4곳, 총 플레이 2–3시간, 최종 칭호 획득 가능.

---

## P3 · 다듬기와 배포 (4주)

- [ ] 온보딩 첫 5분 집중 개선
- [ ] **품질 프리셋 3단계** + 저사양 자동 감지
- [ ] 접근성 (자막, 색맹 대응, 키보드 전용 플레이)
- [ ] 성능 최적화 (예산 문서 기준 달성)
- [ ] 에러 처리 · 저장 데이터 마이그레이션
- [ ] 배포 (Vercel/Cloudflare) + CDN
- [ ] **문화재 정보 전문가 검수** ← 공개 전 필수

**완료 기준:** 공개 배포. 학교 태블릿에서 문제없이 동작.

---

## P4 · 선택 확장 (미정)

우선순위 순:

1. **교사용 대시보드** — 학생 진행도·도감 완성률 확인.
   교육 현장 도입에는 이게 멀티플레이보다 훨씬 중요합니다.
2. **계정 시스템** — 기기 간 진행도 동기화 (Supabase)
3. **멀티플레이** — 같은 유적에 여러 명. 아바타 표시부터 시작
4. 유적 추가 (나주읍성 4대문, 영산강 권역)
5. 오프라인 연계 — 실제 답사 시 QR/위치 기반 보상
6. 다국어 (영어) — 외국인 관광객

## 단계별 판단 게이트

각 단계 끝에서 **계속할지 말지**를 판단합니다. 통과하지 못하면
다음 단계로 넘어가지 않습니다.

| 게이트 | 통과 기준 |
| --- | --- |
| P0 → P1 | 모바일 30fps + 국가유산청 에셋 확보 가능성 확인 |
| **P1 → P2** | **학생 플레이테스트에서 재미와 학습 효과 둘 다 확인** |
| P2 → P3 | 유적 4곳이 같은 엔진 위에서 콘텐츠 작업만으로 완성됨 |
| P3 → 공개 | 전문가 검수 통과 + 성능 예산 달성 |
