# 나주 월드맵 — 지역 분리 설계

> **결론: 나주 전역을 한 씬에 담지 않습니다.**
> 지역마다 별도 맵으로 만들고, 맵 이동으로 잇습니다.

---

## 1. 왜 한 맵에 못 담는가

나주시는 **약 608km²** 입니다. 서울시(605km²)와 비슷한 넓이인데,
문화유산이 시내 한 곳에 모여 있는 게 아니라 **면 단위로 흩어져** 있습니다.

지도를 보면 바로 드러납니다:

- 다시초등학교(다시면) ↔ 국립나주박물관(반남면): 직선으로도 **20km 이상**
- 나주 시내(금성관·향교) ↔ 다도면 불회사: **25km 이상**
- 그 사이는 대부분 **논밭과 야산**

이걸 1:1로 3D화하면 콘텐츠가 아니라 **빈 땅을 걷는 시간**이 게임의 대부분이
됩니다. 그렇다고 거리를 압축해서 한 맵에 우겨넣으면 지리 감각이 왜곡되고
— 이 게임은 "우리 지역을 안다"가 목적이라 그게 치명적입니다.

**그래서 지역별 맵 + 이동 화면**이 맞습니다.
이건 타협이 아니라 이 소재에 맞는 구조입니다.

---

## 2. 지도 분석 — 나주의 문화유산은 어디에 있나

제공된 지도와 국가유산포털 자료를 대조해 정리했습니다.
나주는 **영산강**을 축으로 유산이 배치되어 있습니다. 이게 핵심입니다.

```
            [ 고막천 석교 ]              (북서 끝 · 보물)
                  │
   ┌── 다시면 ────┴───────┐
   │  다시초등학교 ★시작   │            [ 빛가람동 ]
   │  복암리 고분군        │            혁신도시 (현대)
   │  영모정 · 백호문학관   │                 │
   │  회진리               │                 │
   └───────┬───────────────┘                 │
           │        ~~~ 영 산 강 ~~~          │
           │              │                  │
   [ 한국천연염색박물관 ]   │          [ 나주 시내 ]
   [ 석관정 ]             │          금성관 · 나주향교
           │              │          읍성 4대문 · 정수루
   [ 나주영상테마파크 ]     │          심향사
   [ 죽산보 ]         [ 영산포 ]
                     홍어거리 · 등대
           │
   ┌── 반남면 ──────┐              [ 봉황면 ]
   │ 국립나주박물관   │              철천리 칠불석상
   │ 반남고분군      │                    │
   │ (신촌리 금동관)  │              ┌── 다도면 ──┐
   └────────────────┘              │ 불회사      │
                                   │ 운흥사 석장승│
                                   └────────────┘
```

### 지역별 유산 목록

| # | 지역 | 주요 유산 | 성격 |
| --- | --- | --- | --- |
| **1** | **다시면** | **다시초등학교 ★시작**, 복암리 고분군(사적 404호), 영모정, 장춘정, 백호 임제 생가·문학관 | 고대 고분 + 조선 선비문화 |
| **2** | **반남면** | 국립나주박물관, 반남고분군(신촌리·대안리·덕산리), **신촌리 금동관(국보)** | 마한의 중심 |
| **3** | **나주 시내** | 금성관, 나주향교·대성전, 나주읍성 4대문(남고문·동점문·서성문·북망문), 정수루, 심향사 | 조선 목사고을 |
| **4** | **영산포** | 홍어거리, 영산포 등대, 영산강 뱃길 | 근대 물류·생활사 |
| **5** | **다도면** | 불회사, 운흥사 석장승 | 불교문화 |
| **6** | **봉황면** | 철천리 칠불석상(보물 461호), 석불입상 | 불교조각 |
| **7** | **빛가람동** | 혁신도시 | 현대 나주 (대비용) |

### 지도가 알려준 것 — 설계에 반영할 사실

1. **다시초등학교와 복암리 고분군은 같은 다시면입니다.**
   걸어서 볼 거리는 아니지만 **같은 동네**입니다.
   → 시작 지점으로 다시초를 고른 이유가 여기 있습니다.
   "먼 옛날 어딘가"가 아니라 "내가 매일 다니는 동네"에서 시작합니다.

2. **영산강이 모든 것을 잇습니다.**
   복암리도, 반남도, 영산포도, 나주읍성도 전부 영산강 유역입니다.
   → **이동 수단을 영산강 뱃길로** 잡으면, 이동 자체가 학습이 됩니다.
   실제로 영산강은 나주의 물류·문화 대동맥이었습니다.

3. **마한(반남·복암리) → 백제 → 조선(읍성·향교) → 근대(영산포) → 현대(빛가람동)**
   시대가 지역별로 나뉩니다.
   → 지역을 열어가는 순서가 곧 **시대 순서**가 됩니다.
   맵 해금 순서를 시간축에 맞추면 커리큘럼이 저절로 만들어집니다.

## 3. 맵 구조

### 3계층

```
   ┌─────────────────────────────────────────┐
   │  ① 나주 월드맵 (2.5D 지도 화면)           │
   │     영산강을 따라 지역 아이콘이 놓임        │
   │     해금된 지역만 선택 가능                │
   └──────────────┬──────────────────────────┘
                  │ 지역 선택 → 뱃길 이동 연출 → 씬 로드
                  ▼
   ┌─────────────────────────────────────────┐
   │  ② 지역 맵 (3D 씬)                       │
   │     예: 다시초등학교 / 복암리 고분군       │
   │     자유 이동 · NPC · 퀘스트              │
   └──────────────┬──────────────────────────┘
                  │ 입구 진입 → 씬 전환
                  ▼
   ┌─────────────────────────────────────────┐
   │  ③ 실내 · 퍼즐 챔버 (3D 씬)               │
   │     예: 3호분 내부 방탈출                 │
   └─────────────────────────────────────────┘
```

**①은 3D 오픈월드가 아닙니다.** 실제 나주 지형을 본뜬 **기울인 지도판**
위에 지역 아이콘을 얹은 화면입니다. 가볍고, 지리 관계가 한눈에 들어오고,
무엇보다 **만드는 비용이 3D 오픈월드의 1/50** 입니다.

### 이동 연출 — 영산강 뱃길

지역 간 이동은 로딩 화면이 아니라 **짧은 연출**로 만듭니다.

```
   지역 선택
      ↓
   나룻배가 영산강을 따라 이동 (지도 위 경로 애니메이션, 3~5초)
      ↓  이 사이에 다음 씬 에셋을 로드
   도착 지역 3D 씬
```

로딩 시간을 숨기면서, **"영산강이 나주를 이었다"** 는 사실을 매번
몸으로 가르칩니다. 로딩 화면을 학습 기회로 바꾸는 겁니다.

## 4. 맵 목록과 해금 순서

시대 순 = 해금 순. 플레이어는 나주의 역사를 **시간 순서대로 걸어 올라갑니다.**

| 순서 | 맵 ID | 맵 이름 | 해금 조건 | 시대 |
| --- | --- | --- | --- | --- |
| 0 | `dasi-school` | **다시초등학교** ★현재 구현됨 | 처음부터 | 현재 |
| 1 | `bokamri` | 복암리 고분군 | 첫 퀘스트 완료 | 마한~백제 |
| 2 | `naju-museum` | 국립나주박물관 · 반남고분군 | Lv.8 | 마한 |
| 3 | `naju-eupseong` | 나주읍성 (금성관·향교·4대문) | Lv.12 | 조선 |
| 4 | `yeongsanpo` | 영산포 (홍어거리·등대) | Lv.15 | 근대 |
| 5 | `dado` | 다도면 (불회사·운흥사) | Lv.17 | 불교문화 |
| 6 | `bitgaram` | 빛가람동 | Lv.20 | 현대 |

**0번(다시초)이 특별한 이유:** 유일하게 문화유산이 아닌 맵입니다.
플레이어의 **일상**입니다. 여기서 출발해서 한 바퀴 돌고 돌아왔을 때,
같은 운동장이 다르게 보이는 것 — 그게 이 게임이 노리는 마지막 장면입니다.

## 5. 기술 구조

### 씬 레지스트리

맵을 늘릴 때 코드를 고치지 않아도 되도록, 맵을 **데이터로 등록**합니다.

```ts
// src/game/world/registry.ts (예정)
export const MAPS: Record<MapId, MapDef> = {
  'dasi-school': {
    name: '다시초등학교',
    region: '다시면',
    scene: () => import('./maps/DasiSchoolField'),  // 코드 스플리팅
    unlock: { type: 'always' },
    era: '현재',
    worldMapPos: [0.18, 0.22],   // 월드맵 지도 위 좌표 (0~1)
  },
  bokamri: {
    name: '복암리 고분군',
    region: '다시면',
    scene: () => import('./maps/BokamriSite'),
    unlock: { type: 'quest', id: 'dasi-01-first-errand' },
    era: '마한~백제',
    worldMapPos: [0.24, 0.28],
  },
  // ...
}
```

- `scene`이 **동적 import** 입니다. 복암리에 안 간 사람은 복암리 에셋을
  내려받지 않습니다. 맵이 7개로 늘어도 첫 로딩 시간은 그대로입니다.
- `worldMapPos`는 실제 지리 위치를 0~1로 정규화한 값입니다.
  → 월드맵의 아이콘 배치가 **실제 나주 지도와 일치**합니다.
  지리 감각을 지키는 게 이 게임의 목적 중 하나이므로 이건 양보하지 않습니다.

### 씬 전환

```
   useMapStore.travelTo('bokamri')
        │
        ├─ 현재 씬 언마운트 → R3F가 GPU 리소스 정리
        ├─ 뱃길 이동 연출 재생 (3~5초)
        ├─ 다음 씬 청크 로드 (연출과 병렬)
        └─ 새 씬 마운트 · 플레이어를 해당 맵의 spawn에 배치
```

### 맵마다 지켜야 할 계약

새 맵을 추가할 때 필요한 것은 이게 전부입니다:

1. `layout.ts` — 배치 상수 + 충돌 박스 + spawn
2. 씬 컴포넌트 — `{ shadows: boolean }` 을 받는 컴포넌트 하나
3. `src/content/sites/<map>.quests.json` — 퀘스트 데이터
4. `registry.ts` 에 한 줄 등록

**`src/game/player`, `src/game/quest`, `src/ui` 는 건드리지 않습니다.**
이게 지켜지지 않으면 맵 3개쯤에서 프로젝트가 멈춥니다.

## 7. 확인이 필요한 것

이 문서는 제공된 지도 이미지와 공개 자료를 근거로 작성했습니다.
아래는 **확정 전 검증이 필요**합니다:

- 각 유산의 정확한 좌표 (→ `worldMapPos` 값)
- 반남고분군 / 국립나주박물관의 실제 위치 관계
- 다도면·봉황면 유산의 접근 경로 (영산강 뱃길로 닿는 곳이 맞는지 —
  아닐 가능성이 높습니다. 이 경우 육로 이동 연출을 따로 둡니다)
- 지역별 대표 유산 선정이 교육과정과 맞는지
