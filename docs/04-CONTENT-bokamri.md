# 콘텐츠 설계 예시 — 복암리 고분군

1차 수직 슬라이스의 대상입니다. **이 한 곳을 끝까지 만들어보고** 재미가
검증되면, 같은 틀에 나머지 유적을 부어 넣습니다.

> ⚠️ 아래 학습 내용은 **기획 초안**입니다. 실제 구현 전 국립나주박물관 ·
> 국가유산 지식이음의 발굴조사 보고서로 **전수 검증**해야 합니다.
> 확정 전까지 어떤 문장도 게임에 그대로 넣지 않습니다.

---

## 1. 왜 복암리인가

교육용 첫 유적으로 유난히 좋은 조건을 갖고 있습니다.

- **한 무덤에서 시대가 겹쳐 보입니다.** 하나의 분구에 여러 시기의 매장시설이
  중복되어 있어, "시간이 쌓인다"는 개념을 **눈으로** 보여줄 수 있습니다.
  → 층위학 퍼즐의 완벽한 무대.
- **옹관묘가 시각적으로 강렬합니다.** 큰 항아리를 관으로 쓴다는 사실 자체가
  학생에게 즉각적인 "어?"를 유발합니다. 훅으로 최고입니다.
- **마한 → 백제 전환기**라는 굵직한 역사적 맥락을 품고 있습니다.
- **발굴 현장의 서사**가 있습니다. 인디아나 존스 톤을 자연스럽게 얹을 수 있습니다.
- 국립나주박물관이 인접해 있어 **오프라인 연계**(실제 답사)가 가능합니다.

## 2. 공간 구성

```
        [ 나주 월드맵 ]
              │  포탈
              ▼
  ┌───────────────────────────────────┐
  │       복암리 고분군 (야외)          │
  │                                   │
  │   ⛺ 발굴 캠프  ← 진입 지점        │
  │      └ 발굴단장 NPC (!)            │
  │                                   │
  │   🕳 1호분 ── 3호분 ── 트렌치 구역  │
  │                        └ 발굴 미니게임
  │                                   │
  │   🔬 복원 작업대                    │
  │   📋 안내판 ×5  ← 퍼즐 단서 배치    │
  │                                   │
  │   🚪 3호분 내부 입구 (등불 필요)     │
  └───────────────┬───────────────────┘
                  ▼
        [ 3호분 내부 · 퍼즐 챔버 ]
           어둡고 좁음 · 방탈출 구간
```

**설계 의도:** 야외에서 배운 것을 실내 챔버에서 써먹게 합니다.
안내판 5개는 장식이 아니라 **전부 퍼즐의 단서**입니다.
읽지 않은 사람은 챔버에서 막힙니다 — 그게 의도입니다.

## 3. 등장 NPC

| NPC | 역할 | 성격 | 담당 |
| --- | --- | --- | --- |
| **발굴단장** | 메인 퀘스트 기버 | 무뚝뚝하지만 은근히 챙김 | 발굴 · 층위 |
| **기록 담당 연구원** | 서브 퀘스트 | 꼼꼼하고 말이 많음 | 도감 · 기록 |
| **복원 기술자** | 제작 담당 | 손재주 자랑이 심함 | 토기 복원 |
| **견학 온 학생** | 해설 대상 | 질문이 끝없음 | `INTERPRET` 퀘스트 |
| **마을 어르신** | 구전 · 분위기 | 옛 이야기를 함 | 지역 맥락 |

`견학 온 학생` NPC가 중요합니다. 플레이어가 배운 걸 **설명하게 만드는 장치**이며,
"해설사가 된다"는 판타지를 매 순간 확인시켜 줍니다.

## 5. 퍼즐 상세 — `bokamri-05-layers` (방탈출)

3호분 내부 챔버. 이 유적의 클라이맥스입니다.

```
  [입장] 등불 필요. 어둡고, 벽면에 층위 단면이 드러나 있음.
     │
     ├─ 1단계 · 층위 정렬
     │    벽의 지층 4개를 오래된 순서로 배치
     │    단서 → 야외 안내판 #2 ("아래에 있을수록 오래된 것")
     │
     ├─ 2단계 · 매장시설 식별
     │    3개의 매장시설이 각각 어느 시기인지 판정
     │    단서 → 야외에서 본 옹관/석실의 형태 차이
     │
     ├─ 3단계 · 부장품 배치
     │    유물을 대응하는 매장시설에 배치
     │    단서 → 복원 작업대에서 만든 토기의 양식
     │
     └─ [해결] 챔버 조명 점등 → 3호분 전체 단면 연출
              "하나의 무덤에 400년이 쌓여 있다"
              → 도감 3개 동시 해금
```

**단서가 전부 챔버 밖에 있습니다.** 그래서 야외를 대충 지나친 플레이어는
반드시 되돌아가야 하고, 되돌아가면 이번엔 안내판을 읽습니다.
**"읽어라"라고 말하지 않고 읽게 만드는 것** — 이게 이 게임의 방법입니다.

## 8. 이후 유적으로의 확장

복암리에서 만든 것 중 **재사용되는 것**:

- 퀘스트 엔진 · 퍼즐 아키타입 6종 (그대로)
- NPC 대화 시스템 · 캐릭터 스켈레톤 (그대로)
- 발굴/복원 미니게임 (파라미터만 교체)

**새로 만들어야 하는 것**: 유적별 지형·건축 모델, 퀘스트 JSON, 도감 항목.

즉 두 번째 유적부터는 **콘텐츠 작업만** 남습니다. 이게 1차에서 한 곳만
깊게 파는 이유입니다.
